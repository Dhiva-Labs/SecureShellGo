### Added
- A diagnostics log for bug reports. Errors and crashes are recorded on this device while "Keep a diagnostics log" is on in Settings, with passwords, private keys, tokens and saved credentials removed before anything is written. Copy it to the clipboard, view it, or clear it from Settings. It never leaves the device unless you paste it somewhere, stays small, and turning it off deletes it.
- App lock on Windows, unlocked with Windows Hello (your PIN, fingerprint or face). If the Hello prompt cannot be shown, the app stays locked.
- Backups can include your trusted host keys, if you tick "Include trusted host keys" when exporting, so a restored device recognises your servers without asking again. On import they are added to the keys this device already trusts. A key this device already trusts for a server is never replaced by the one in the backup.
- "Save to…" for backups: save to any folder, or to a cloud drive such as Google Drive, OneDrive or Dropbox, through the system's save screen. "Save to Downloads" is still there.
